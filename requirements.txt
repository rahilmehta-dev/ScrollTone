# ── Chatterbox engine (optional voice cloning) ─────────────────────────────────
# The app shells out to a SEPARATE venv for this engine at runtime
# (backend/engines/runner.py hardcodes .venv-chatterbox) — installing these
# packages into the main venv is not enough to enable Chatterbox. See
# documentation/engines.md for the .venv-chatterbox setup command.
# Model weights (~3GB) download from HuggingFace on first use. This app always
# runs Chatterbox on CPU (backend/engines/chatterbox_synth.py hardcodes
# device="cpu"), never MPS/CUDA — Chatterbox's autoregressive decoder has a
# confirmed, severe memory leak on Apple's MPS backend (grew past 78GB RSS in
# testing). Do not override this without re-validating from scratch.
